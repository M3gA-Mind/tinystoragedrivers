# v2 public item inventory

This is the source audit required by issue 23. It enumerates public
definitions, associated methods, public fields, and re-export declarations in
the six current crates at epic base `ae2fc08`. Line references are source
locations. A public name reached through a root re-export is listed at both
its definition and re-export site, because both paths are public API.

| `tinystoragedrivers-tinybus` | [tinybus](tinystoragedrivers-tinybus.md) |

The audit includes public members below private modules: Rust privacy makes
those available only when a public parent exports them, but their names still
need a destination. Destination labels follow the v2 split in
[`../primitives-v2.md`](../primitives-v2.md): values and wire DTOs to `-types`,
traits to `-api`, engine implementations to their primitive crate, test-only
support to `-testkit`, product model/policy to its consumer, OpenHuman-owned
composition/configuration to the host, and superseded functionality to
deletion.

The inventory was generated by scanning all non-test Rust source files for
public item declarations, public members, and `pub use` re-exports. The
crate-root re-export lists in each `src/lib.rs` are included. Review it against
`rg '^\s*pub\s' crates/<crate>/src` when code moves; destination labels are
architectural decisions, not an assertion that the v1 implementation already
has the v2 crate boundaries.
